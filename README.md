# SOC Lab with Wazuh

## Overview
Built a hands-on SOC environment to detect and analyze cyber attacks using Wazuh.

## Architecture
- SIEM: Wazuh (Ubuntu)
- Attacker: Kali Linux
- Target: Ubuntu Machine

## Simulated Attacks
- SSH brute force
- Nmap network scan

## Detection & Analysis
- Alerts generated in Wazuh
- Log correlation and investigation

## Tools Used
- Wazuh
- Kali Linux
- Nmap
